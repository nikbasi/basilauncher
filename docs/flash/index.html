Flash Basilauncher — first install only

LilyGO T5 E-Paper S3 Pro — one-click install from Chrome or Edge.

Before you start

  1. Use Chrome or Edge on desktop (Web Serial).
  2. Plug the T5 Pro in with a data-capable USB cable.
  3. Close other serial monitors / PlatformIO monitors.

Install

Writes one full image at 0x0 (bootloader, partitions, hub). First install only.

Loading firmware…

Web Serial is not supported in this browser. Use Chrome/Edge, or flash with esptool from the Releases page. Permission to use the serial port was denied.

Pick the port labeled like USB JTAG/serial or Espressif. For later hub updates use the smaller factory image so guest apps stay intact.

Manual (esptool)

Same one-file result:

esptool.py --chip esp32s3 -p PORT write-flash 0x0 basilauncher-*-full.bin
