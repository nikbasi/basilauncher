Flash Basilauncher

LilyGO T5 E-Paper S3 Pro — one-click install from Chrome or Edge.

Before you start

  1. Use Chrome or Edge on desktop (Web Serial).
  2. Plug the T5 Pro in with a data-capable USB cable.
  3. Close other serial monitors / PlatformIO monitors.

Install

Writes the full image (custom bootloader + partitions + hub) at 0x0. Otadata is cleared inside that image so the device boots Basilauncher.

Web Serial is not supported in this browser. Use Chrome/Edge, or flash with esptool from the Releases page. Permission to use the serial port was denied.

Pick the port labeled like USB JTAG/serial or Espressif. First install only — for later hub updates prefer the smaller factory image via USB tools so guest apps stay intact.

Manual (esptool)

Same result as the button:

esptool.py --chip esp32s3 -p PORT write-flash 0x0 basilauncher-*-full.bin
esptool.py --chip esp32s3 -p PORT erase-region 0xe000 0x2000

The erase step is optional if you flashed the full image (it already contains erased otadata), but harmless and recommended after a three-file flash.
